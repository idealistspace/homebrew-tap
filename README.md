# IdealistSpace Homebrew Tap

Command-line tools from [IdealistSpace](https://github.com/idealistspace).

```sh
brew tap idealistspace/tap
```

## Formulae

| Formula | Description | Status |
|---|---|---|
| `dbm` | Save, search, read, and annotate your [DoubleMemory](https://doublememory.com) library from the terminal. Requires the DoubleMemory Mac app. | Not yet released |
